# 파이썬 기초 개념 요약

## 변수와 자료형

### 변수 (Variable)
- 값을 저장하기 위한 이름


```
x = 10
name = "seolhowol"
```

### 기본 자료형
> int (정수형)

- 소수점이 없는 정수 표현

```
a = 1
```

> float (실수형)

- 소수점을 포함한 숫자

```
b = 1.1
```

> str (문자열)

- 문장? 저장

- 작은따옴표('') 또는 큰따옴표("") 사용

```

c = "hello"
```


> bool (논리형)

- 참(True) 또는 거짓(False)
- 1 or 0
- 조건문에서 사용
```

2 = 3
```

## 조건문과 반복문
### 조건문 (if)

> 조건이 참일 때 코드 실행

- elif, else 사용 가능
```

if x > 0:
    print("양수")
elif x == 0:
    print("0")
else:
    print("음수")
```


### 반복문 (for)

- 반복 횟수가 정해진 경우 주로 사용

```

for i in range(5):
    print(i)
```

### 반복문 (while)
- 조건이 참인 동안 반복
- 별로 인 듯

```
x = 10
while x > 0:
    x -= 1
```
