# 리스트(List)와 셋(Set)의 속도 차이와 해시 테이블(Hash Table)
## 속도 비교: 시간 복잡도
> 시간 복잡도
- 특정 알고리즘이 문제를 해결하는 데 걸리는 시간의 양을 나타내는 개념
- 입력 데이터가 커질 때 실행 시간이 얼마나 더 걸리는지를 분석
- 실제 시간 대신, 알고리즘이 수행하는 기본적인 연산(비교, 대입 등)의 횟수

> 주요 표기법
- 빅오 표기법: 최악의 경우
- 빅오메가 표기법: 최선의 경우
- 빅세타 표기법: 평균적인 경우

> 중요: 알고리즘 비교 과정에서는 항상 최악의 경우를 비교하기 때문에 빅오 표기법을 많이 사용함

## 리스트 vs. 셋
> 리스트의 연산
- 리스트는 데이터를 메모리에 순서대로 저장하는 '동적 배열' 구조
- 처음부터 끝까지 하나씩 비교하며 찾음
- 시간 복잡도: O(n)

> 셋의 연산
- 셋은 데이터를 해시 함수를 이용해 저장하는 '해시 테이블' 구조
- 시간 복잡도: O(1)

## Python의 Dictionary와 Set은 내부적으로 어떻게 데이터를 저장하는가? 
> 해시 테이블
- 입력된 키(문자열, 숫자 등)를 고정된 길이의 해시 값(정수)으로 변환
- 해시 값을 배열의 인덱스로 변환하여, 데이터가 저장될 메모리 위치를 결정

> 딕셔너리
- 키(key)와 값(value) 쌍으로 구성되며, 키는 고유
- 저장 방식
  1. key의 해시 값을 구하고 이를 인덱스
  2. 해당 인덱스에 (key, value) 쌍을 저장
  3. 다른 키가 같은 인덱스를 가리킨다면(해시 충돌), 추가적인 처리(예: 연결 리스트로 연결)를 통해 데이터를 관리

> 세트
- 중복을 허용하지 않는 값들의 모음이며, 값 자체가 키처럼 동작
- 저장 방식:
  1. 저장하려는 값(value)의 해시 값을 구하고 인덱스로 변환
  2. 해당 인덱스에 값만 저장
  3. 중복된 값을 추가하려 하면, 해시 충돌 여부를 확인하고 이미 존재하면 무시
